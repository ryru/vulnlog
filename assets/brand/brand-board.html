Vulnlog identity

The name is a key. Your file is the value.

This board shows how the Vulnlog identity looks. The rules and exact values are in devdoc/Brand.adoc, the logo files in assets/brand/.

On paper
On night

The idea

Vulnlog is a declarative format. You write what is true about a vulnerability, and tools generate the rest. A colon after the name makes that visible: the name becomes a key that waits for your answer. The letters are drawn for Vulnlog from a single line, with rounded corners. The colon is the only fully round shape and the only colour.

Vulnlog: not affected
Vulnlog: fixed in 2.4.1
Vulnlog: under investigation

The mark

Where the full name does not fit, the V and the colon stand on a raspberry tile. It is drawn a little bolder so it holds at 16 pixels.

Colour

One brand colour. Every coloured value is the same on paper and on night. Only the neutrals change with the theme, and neither theme uses pure white or pure black.

Type

Figtree for the website and the docs, JetBrains Mono for code. The HTML report uses the reader's system font, because it must work offline.

Record your assessment once

You record each vulnerability as an entry in the Vulnlog file. An entry says which releases are affected, your verdict, the reasoning behind it, and what you plan to do.

Writing the name

  • Vulnlog in every sentence, with a capital V
  • vulnlog only as a command, package or file name
  • The colon belongs to the logo, never to running text
